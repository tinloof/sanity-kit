Add the opt-in `@tinloof/sanity-studio/table` entry point with `defineTableSchema` and `withTableMerging`. Supports horizontal cell merge/split, logical column editing, keyed edits, and configurable rich clipboard rendering while preserving the table/rows/cells/value data shape. Existing Portable Text fields are unchanged. Table integration requires `@portabletext/editor` 8.1.3 and is verified with Sanity 6.13.1.
