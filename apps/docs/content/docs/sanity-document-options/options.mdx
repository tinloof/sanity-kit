# Plugin Options

```ts
documentOptions({
  structure?: {
    locales?: Locale[];        // Locale configuration
    hide?: string[];           // Document types to omit from autogenerated structure
    toolTitle?: string;        // Structure tool title
    localeFieldName?: string;  // Locale field name (default: "locale")
    keepPanesOnCreate?: boolean; // Forward to Sanity; omitted uses its default
  } | false,                   // Pass false to disable structure tool
});
```

`structure.keepPanesOnCreate` forwards directly to Sanity's structure tool. Set it to `true` to retain the current hierarchy when creating from a pane that offers the matching create action or initial value template. Omit it to use Sanity's default; explicit `false` is forwarded unchanged.

# Schema Options

```ts
interface DocumentOptions {
  // Structure configuration
  structureGroup?: string;
  structureOptions?:
    | false
    | StructureBuiltinOptions
    | ((
        S: StructureBuilder,
        context: StructureResolverContext,
      ) => ListItemBuilder);
  localized?: boolean;

  // Document options
  document?: {
    actions?: (prev, context) => DocumentActionComponent[];
    badges?: (prev, context) => DocumentBadgeComponent[];
    newDocumentOptions?: (prev, context) => TemplateItem[];
  };

  // Schema options
  schema?: {
    templates?: Template[] | ((prev, context) => Template[]);
  };
}
```

Set a document's `options.structureOptions` to `false` to omit its autogenerated root or group entry. Groups containing only hidden types are omitted, including nested groups. The schema remains available to custom structure callbacks, references, templates, and creation menus. Existing singleton restrictions and explicit template or creation customizations still apply. Global `structure.hide` remains supported and takes precedence over callbacks and built-in options.

# Built-in Structure Options

```ts
type StructureBuiltinOptions = {
  singleton?: boolean | { id?: string };
  orderable?: boolean;
  icon?: React.ComponentType | React.ReactNode;
  title?: string;
  views?: (S: StructureBuilder) => (View | ViewBuilder)[];
};
```
