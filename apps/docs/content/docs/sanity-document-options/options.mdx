# Plugin Options

```ts
import {
  documentOptions,
  type DocumentOptionsPluginOptions,
} from "@tinloof/sanity-document-options";

const options: DocumentOptionsPluginOptions = {
  structure: {
    locales: [{id: "en", title: "English"}],
    hide: ["internalNote"],
    toolTitle: "Content",
    localeFieldName: "locale",
    keepPanesOnCreate: true,
  },
  abstracts: {singleton: true, sync: true, orderable: true},
};

documentOptions(options);
```

Call `documentOptions()` to use the defaults, or pass an options object as above. `DocumentOptionsStructureOptions` is the object accepted by `structure`. The existing `DocumentOptionsProps` and `InlineStructureProps` names remain supported as compatibility aliases; no migration is required.

`structure.keepPanesOnCreate` forwards directly to Sanity's structure tool. Set it to `true` to retain the current hierarchy when creating from a pane that offers the matching create action or initial value template. Omit it to use Sanity's default; explicit `false` is forwarded unchanged.

# Schema Options

```ts
interface DocumentOptions {
  // Structure configuration
  structureGroup?: string | string[];
  structureOptions?:
    | false
    | StructureBuiltinOptions
    | ((
        S: StructureBuilder,
        context: StructureResolverContext,
      ) => ListItemBuilder);
  localized?: boolean;

  // Document options
  document?: {
    actions?: (prev, context) => DocumentActionComponent[];
    badges?: (prev, context) => DocumentBadgeComponent[];
    newDocumentOptions?: (prev, context) => TemplateItem[];
  };

  // Schema options
  schema?: {
    templates?: Template[] | ((prev, context) => Template[]);
  };
}
```

Set a document's `options.structureOptions` to `false` to omit its autogenerated root or group entry. Groups containing only hidden types are omitted, including nested groups. The schema remains available to custom structure callbacks, references, templates, and creation menus. Existing singleton restrictions and explicit template or creation customizations still apply. Global `structure.hide` remains supported and takes precedence over callbacks and built-in options.

Use an array for nested groups, for example `structureGroup: ["content", "articles"]`. Hidden-only groups and their empty ancestors are omitted.

Choose the visibility control that matches its scope:

- `documentOptions({structure: false})` disables the generated structure tool but keeps document actions, badges, templates, and abstracts.
- `documentOptions({structure: {hide: [...]}})` centrally omits named types from the generated structure.
- A schema's `options.structureOptions: false` locally omits only that type's generated entry, which is useful when another schema callback owns its navigation.

# Built-in Structure Options

```ts
type StructureBuiltinOptions = {
  singleton?: boolean | { id?: string };
  orderable?: boolean;
  icon?: React.ComponentType | React.ReactNode;
  title?: string;
  views?: (S: StructureBuilder) => (View | ViewBuilder)[];
};
```
