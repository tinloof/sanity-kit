# @tinloof/sanity-extends

## 3.0.0

### Major Changes

- Require Sanity 6.12 or later within major 6 (`^6.12.0`) and drop Sanity 5 support. Projects remaining on Sanity 5 should keep using the previous package major. Update schema-option types and build tooling without changing schema merge behavior or the package's Node engine requirement.
